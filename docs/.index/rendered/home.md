# OKF Agent Graph

OKF Agent Graph Engineering Runtime (AGER) is a portable, framework-neutral
way to describe multi-agent systems as readable Markdown plus YAML. Start with
the user guide, use the AGER specification as the contract, and inspect the
design document and code walkthrough before changing the plugin.
